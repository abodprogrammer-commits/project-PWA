# 📄 تطبيق الماسح والموثق الذكي للمستندات Pro

تطبيق ويب تقدمي (**PWA - Progressive Web App**) متكامل، مصمم ليعمل كـ "ماسح ضوئي ذكي" للوثائق والمستندات عبر كاميرا الهاتف أو الكمبيوتر مباشرة، مع إمكانية العمل الكامل **بدون الاتصال بالإنترنت (Offline Mode)**.

---

## 🌟 نظرة عامة عن المشروع

يهدف هذا المشروع إلى توفير أداة محددة وسريعة للمستخدمين لالتقاط المستندات، معالجتها، استخراج النصوص منها، وحفظها أو تصديرها بفرز متقدم، دون الحاجة لتثبيت تطبيقات معقدة أو الاتصال بالخوادم الخارجية لتعديل البيانات.

---

## 🚀 المميزات والوظائف الرئيسية

### 1. 📸 العدسة والتحكم بالكاميرا
* **تشغيل/إيقاف الكاميرا:** التقاط الصور والمستندات بدقة عبر البث المباشر.
* **التحكم بالفلاش (Torch Light):** إمكانية إضاءة فلاش الهاتف أثناء الالتقاط في الأماكن المظلمة.
* **قراءة أكواد الـ QR:** التعرف السريع والمباشر على الرموز الشريطية واستخراج روابطها أو بياناتها.

### 2. 🎨 معالجة وتصفية الصور
* **الفلتر الأبيض والأسود:** تحويل صور المستندات إلى وضعية الأبيض والأسود (B&W) لزيادة وضوح النصوص وتقليل حبر الطباعة.
* **تدوير الوثيقة:** إمكانية تدوير الصورة بمقدار 90 درجة للوصول للاتجاه المناسب.
* **تسمية وتصنيف المستندات:** إمكانية كتابة عنوان للمستند وتحديد تصنيفه (عام، فواتير، شخصي، عمل).

### 3. 📂 الأرشيف وقاعدة البيانات المحلية
* **تخزين محلي آمن (IndexedDB):** يتم حفظ جميع المستندات الملتقطة داخل ذاكرة المتصفح مباشرة لضمان الخصوصية والعمل أوفلاين.
* **تصنيف وتصفية السجلات:** إمكانية استعراض الوثائق بناءً على قسمها (فواتير، وثائق عمل، إلخ) مع زر لإدارة أو مسح الأرشيف.

### 4. 🔍 التعرف الضوئي على النصوص (OCR)
* **استخراج النصوص من الصور:** تحليل محتوى الصورة الملتصقة وقراءة الكلمات والأرقام المكتوبة فيها تحليلياً لتحويلها إلى نص قابل للنسخ والتعديل.

### 5. 📄 التصدير والمشاركة والمتطلبات المتقدمة
* **تصدير بصيغة PDF:** تحويل الوثائق إلى ملفات PDF جاهزة للتنزيل أو الإرسال.
* **المشاركة والطباعة الفورية:** إمكانية طباعة المستند مباشرة من التطبيق أو مشاركته عبر برامج التواصل.
* **مراقبة حالة البطارية:** عرض مستوى شحن جهاز المستخدم وحالتها لتنبيهه عند انخفاض الطاقة أثناء معالجة المستندات.
* **الإشعارات والمزامنة:** دعم تنبيهات الحفظ وإمكانية المزامنة السحابية الخلفية.

---

## 🛠️ التقنيات والمكتبات البرمجية المستخدمة

* **التصميم والواجهة:** HTML5, Tailwind CSS (تنسيق عصري متجاوب مع جميع الشاشات).
* **تقنية التطبيقات التقدمية (PWA):** Service Workers & Web App Manifest (لتثبيت التطبيق على الشاشة الرئيسية والعمل بدون إنترنت).
* **قاعدة البيانات:** IndexedDB (لتخزين الصور والبيانات محلياً).
* **مكتبة jsQR:** لاستخراج وقراءة بيانات أكياس الـ QR.
* **مكتبة jsPDF:** لتوليد وبناء ملفات الـ PDF.
* **مكتبة Tesseract.js:** للتعرف الآلي والذكي على النصوص داخل الصور (OCR).

---

## 📑 طريقة الاستخدام

1. افتح التطبيق عبر المتصفح أو قم بتثبيته على شاشة جهازك بالضغط على زر **📲 تثبيت التطبيق**.
2. اضغط على **🎬 تشغيل الكاميرا** لمنح التطبيق صلاحية الوصول للكاميرا.
3. وجه الكاميرا نحو المستند ثم اضغط على **📸 التقاط وثيقة** أو **🔍 قراءة QR**.
4. حدد تصنيف المستند وقم بتطبيق الفلاتر (مثل الأبيض والأسود) إن أردت.
5. استعرض المستند في الأرشيف لمعاينته، استخراج النص منه عبر **OCR**، أو تصديره إلى ملف **PDF**.
